# Лабораторна робота №1 (Варіант 9 - Прокат автомобілів)

## Опис
Програма обчислює вартість прокату автомобілів: базову ціну, знижку за тривалість і страховий збір.
Написана у функціональному стилі:
- `core.py` містить чисті функції (без мутацій, глобалів та `print`).
- `app.py` відповідає за I/O (вивід на екран), функція `run()`.
- `main.py` - точка входу програми.
- Політики знижки, страхування та фільтра передаються через `typing.Callable`.
- `make_processor()` - функція вищого порядку, яка повертає налаштований обробник.
- `tests/test_core.py` містить pytest-тести на референтну прозорість, відсутність мутацій і Callable-політики.

## Як запустити програму
```bash
pip install -r requirements.txt
python main.py
```

## Запуск тестів
```bash
python -m pytest -v
```
